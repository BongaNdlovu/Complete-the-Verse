# Pilgrimage Journey Scenes (Arcs II–V) Asset Prompt Specifications

## 1. Overview & Pipeline Standards

This specification provides the master prompt roster and artistic direction for the remaining **40 map journey scenes** across Arcs II–V in *Complete the Verse*.

### Pipeline Target Specifications
- **Master Aspect Ratio**: `4:3` (1024×768) or `16:9` cinematic master, bounded and web-optimized.
- **Runtime Format**: Lossless / High-Efficiency WebP (`.webp`) under 220 KB per asset.
- **Art Style & Tone**: Biblical thriller, cinematic atmosphere, historical antiquity, volumetric haze, atmospheric dust, rich golden-amber to deep-crimson color grading, dramatic contrast, and grounded archaeological realism.
